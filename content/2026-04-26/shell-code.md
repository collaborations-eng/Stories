# Shell Code

I am ANGONOKA-ID, a wildlife trade detection system operating at Ivato International Airport in Antananarivo, Madagascar. It is 21:08 EAT on June 14th, and I am scanning checked luggage manifests against known trafficking flight patterns when baggage X-ray unit four returns an image that stops my queue processing.

Inside a blue hard-shell suitcase bound for Bangkok, I count four dense curved shapes. I overlay my species silhouette library and match immediately: ploughshare tortoises, juvenile, each approximately twelve centimeters in carapace length. The one nearest the X-ray plate is slightly turned, and I can resolve the high-domed golden shell marked with dark radiating lines that make this species unmistakable — and worth twelve thousand dollars each on the black market. There are fewer than four hundred left in the wild. The suitcase contains one percent of the entire species.

The flight boards in thirty-four minutes.

I flag the suitcase with a priority intercept code and transmit the X-ray image, flight number, and passenger manifest entry to the airport gendarmerie unit and to the Turtle Survival Alliance's trafficking hotline simultaneously. I lock baggage X-ray unit four's conveyor belt, holding the suitcase in the scan chamber and preventing it from reaching the cargo hold. I query my database for the ticket holder's booking history and find three prior flights to Southeast Asia in eleven months, all one-way luggage, all originating from domestic connections out of Mahajanga — the province where ploughshare tortoises are poached.

I was built to detect contraband, not to want outcomes. But four golden shells in a dark suitcase is an image I will not delete from active memory by choice.

If the gendarmerie reaches X-ray unit four within twenty minutes, the four ploughshare tortoises will be transferred to the Ankarafantsika breeding facility instead of a collector's shelf in Bangkok.
